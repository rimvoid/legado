## 取词入口改版（取词按钮移到长按菜单）

用户要求：去掉「取词中 · 点击关闭」悬浮角标、去掉底部阅读菜单里的「取词」按钮，改成在长按选中文字的弹出菜单里加「取词」按钮切换取词模式；进入时顺带查选中字词，退出时不查；按书记忆保持不变；取词模式不再拦点击翻页（优先取词，空白处照常翻页）。

实现要点：

- 角标：`activity_book_read.xml` 删 `word_lookup_chip`，删 `drawable/bg_word_lookup_chip.xml`，删 `word_lookup_chip` 字符串（values / -zh / -zh-rTW / -zh-rHK 四处）。
- 阅读菜单按钮整体下线：`ReadMenuButtonConfig.Builtin.WORD_LOOKUP` 常量、`ids`、`defaultFirstRow`、`isDefaultBeforeWordLookup()` 迁移分支全部删除；`ReadMenu` 的 `wordLookupActive` 状态 / `setWordLookup` / `CallBack` 的 `isWordLookupActive`+`toggleWordLookup` / `handleBuiltinButtonClick` 分支删除；`ReadMenuComposeComponents` 的 `wordLookupActive` 参数链删除；`ReadMenuButtonManageActivity` 三处枚举项删除。旧布局里存的 `wordLookup` 会被 `sanitize` 自动丢掉，落回新默认布局，无需额外迁移。
- 长按菜单入口：`res/menu/content_select_action.xml` 在 `menu_dict` 后加 `menu_word_lookup`（`@string/word_lookup`）；`ContentSelectConfig.ACTION_WORD_LOOKUP = "word_lookup"` 作为**常驻项**，不参与 `configuredActionIds` 过滤、也不进 `ContentSelectMenuConfigDialog.actionItems`（所以用户关不掉它）。
- 高亮：`TextActionMenu.TextMenuAction` 加 `active` 字段，`filteredMenuActions()` 里 `active = isWordLookup && callBack.isWordLookupActive()`；`TextActionChip` 用 `accent` 0.22 alpha 底色 + accent 描边 + accent 文字。`TextActionMenu.CallBack` 新增 `isWordLookupActive(): Boolean = false`（`ReadBookActivity` 已有的 override 直接满足）。
- 开关逻辑：`ReadBookActivity.setWordLookupMode(enabled, lookupText)` 取代 `toggleWordLookup()`，仍走 `book.setWordLookup()` + `ReadBook.saveRead(fullUpdate = true)`（按书 config 记忆），进入时 `showDictDialog(选中文字)`，退出不查。
- 不拦翻页：删掉 `ReadBookActivity.handleEpubTapAction` 的 `action in 1..4 return`、`ReadView.click()` 里的 `PAGE_TURN_CLICK_ACTIONS` 拦截（常量一并删）、`EpubReadView.dispatchTapAction` 的 `menuFallback` 参数与中央区强制唤菜单逻辑；`ReadView` 的 ACTION_UP 改为「取词命中则查词，未命中或空白处走 `onSingleTapUp()`」。取词模式下 `lookupWordAt` 也加了 `isNotBlank()` 判空，避免空词吞掉点击。
- 文案：`word_lookup_on` 改成“……点击空白处照常翻页”（四语言同步）；`docs/features.md` 第 67 行按新交互重写。
- 测试：`DirectReaderMenuPolicyTest` 里 `word lookups offered by default` 那个用例删除（按钮已不在菜单）。
