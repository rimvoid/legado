# 阅读 Archive 功能说明

阅读 Archive 是基于 Legado / 阅读 Sigma 分支继续开发的 Android 阅读器。支持自行添加书源、阅读本地书籍，并提供书架管理、听书、主题、AI 和自动任务等功能。应用不内置书籍内容，书源与阅读内容由使用者自行添加。

本文介绍第十四版功能。安装包见 [GitHub Releases](https://github.com/Rimchars/legado/releases) 和 [Gitee Releases](https://gitee.com/zziji/legado/releases)。

## 阅读与书籍管理

- 支持书源搜索、发现、换源、目录更新和章节缓存，以及本地 TXT、EPUB 书籍。
- 书架支持列表与网格、分组、自定义标签、筛选和批量管理。
- 详情页提供简介、目录、阅读进度、分组、标签与定时检测更新；支持沉浸式封面布局。
- 可编辑书名、作者、封面、简介与自定义标签。长标签可以换行，较多内容可以滚动查看。
- 支持书签、阅读记录、进度同步、备份与恢复。

## 原生正文与 EPUB 排版

普通 TXT 和书源正文可以在「其它设置 → 普通正文渲染方式」选择原生或 EPUB 渲染。两种模式分别保存排版设置；普通正文的 EPUB 模式与 EPUB 文件共用 EPUB 排版配置。

| 项目 | 原生正文 | 普通正文的 EPUB 模式 | EPUB 文件 |
| --- | --- | --- | --- |
| 基础排版 | 字体、字号、颜色、行距、段距、缩进等 | 通过 WebView 排版，保留原书目录与字符进度 | 使用书内 XHTML、CSS、图片与链接 |
| 替换净化 | 支持 | 在生成页面前处理原始章节文本 | 按 EPUB 阅读模式的既有处理方式 |
| 高亮规则 | 字体、字号、文字色、背景色及基础文字装饰 | 支持图片背景、边框等 CSS 高亮效果 | 支持图片背景、边框等 CSS 高亮效果 |
| 自定义页面模板 | 不适用 | 支持首页与续页模板 | 保留书籍自身排版 |
| 段落规则与 pclick | 沿用原生能力 | 当前不启用；原始图片 click 可使用 | 按 EPUB 自身内容与链接处理 |

EPUB 支持覆盖、滑动、仿真等翻页方式和独立阅读样式。默认策略优先保证页面准备充分；流畅模式最多预热 4 个相邻章节，极致模式最多预热 6 个，并扩大相邻页面缓存。同章页面尽量复用已经排版的 WebView，手指按下时暂缓启动新的后台章节排版。

分页会综合正文行、段落、图片和装饰占用的空间，改善页面底部留白、裁切和跨页衔接。短章末页、强制分页与复杂插图仍保留适合内容的布局，不保证每一页都铺满。

## 高亮规则

- 支持从本地 `.red` 文件导入 Reeden 高亮规则，并导出规则文件。高亮导入入口只接受本地文件。
- 管理页支持按名称、分组和匹配内容搜索，支持启用、停用、排序、编辑、删除及作用范围设置。
- 支持导出全部规则或当前搜索结果，便于整理和分享。
- 可调整匹配规则、文字样式和背景图案，并在编辑时预览。
- 可直接从阅读素材中选择字体或背景图片；选择字体后自动更新 `font-family`。
- 原生正文使用基础文字样式；完整图片图案与复杂 CSS 效果通过 EPUB 渲染展示。

本轮完善了多行高亮的图案头尾、左右边缘、标点与引号开头、短末行，以及图片气泡与文字的垂直对齐。异常正则和损坏的资源会进行检查，避免长时间拖住正文处理或覆盖正常配置。

## 页面模板

在普通正文的 EPUB 模式中，打开「阅读样式 → 页面模板」。

- 内置「星幕月相」和「古籍竖排」，分别展示横排与竖排的创作方式。
- 可复制模板，自行编辑首页 HTML、续页 HTML、CSS 和 JavaScript。
- 支持多正文区域、动态页眉页脚、图片、字体和当前页面动效。
- 支持预览、应用、导入、导出、删除和模板库独立备份。
- 动效会随页面可见状态暂停、恢复或收敛为静态画面；异常模板可以回退到「原有排版」。

模板库使用独立备份；普通全量备份不再打包整个模板库。阅读样式分享仍携带其关联的模板。编写方法见 [页面模板说明](reader-templates.md)。

## 阅读素材

- 统一管理图片与字体，支持搜索、分类、缩略图和字体预览。
- 可浏览本地来源文件夹，也可直接导入图片或字体文件。
- 已导入素材保存在应用素材库中，移动原文件不会使已导入的引用失效。
- 支持重命名、导出、复制引用和查看已保存的使用位置。
- 高亮规则与页面模板可以共用同一份图片、字体；导出时会携带所引用的素材。
- 删除仍被已保存规则或模板使用的素材时会提示对应引用，避免无意破坏已有样式。

## 界面、主题与听书

- 支持日间和夜间主题、背景图片、颜色、字体与界面圆角，以及主题导入导出。
- 阅读页可以配置正文菜单、页眉页脚、高级标题、Lottie 装饰和段评气泡。
- 长按正文选中字词时，菜单中有「取词」按钮可切换取词模式：开启时按钮高亮并立即查询选中字词，之后点击单词即弹出词典释义，点到空白处照常按点击区域翻页或呼出菜单，再次长按点按该按钮即可退出，开关按书单独记忆；取词使用「我的 → 词典规则」中启用的规则，原生正文与 EPUB 直读均可使用。
- 支持系统 TTS 与网络 TTS、语速与定时停止设置、朗读进度和原文跟随。
- 系统听书悬浮窗可跨应用显示，提供贴边球、控制胶囊和原文窗口；需要系统悬浮窗权限。
- 支持漫画与视频阅读入口、章节信息和相应播放控制。

## AI、定时任务与网络

- AI 助手可配置服务，使用书源搜索、书籍和章节读取、阅读记录查询、联网搜索等工具，并提供图片等扩展能力；具体功能取决于配置的服务。
- 定时任务支持创建、编辑、启停、导入和导出，可按计划执行书籍更新、目录刷新及通知。定时任务功能感谢明月的贡献与支持。
- 「我的 → 其它设置 → 网络与 DNS」支持系统 DNS、DoH、域名例外与功能分流，内置多个服务并支持自定义和测速。
- DoH 默认关闭，保存配置后重启生效。WebView 网页自身发起的请求、系统或第三方 TTS 不会自动套用原生网络客户端的分流设置。详见 [网络与 DNS](doh-network.md)。
- 支持本地、WebDAV 和对象存储等备份方式，以及存储容器管理。

## 当前验证范围

第十四版已完成 JVM 回归、浏览器渲染比较、静态检查和安装包校验。复杂模板、高亮图案和系统 WebView 的实际表现仍需设备反馈；当前未完成 Android 真机显示、触控或整机帧率验收。
